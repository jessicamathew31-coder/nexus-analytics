# NEXUS ANALYTICS
### Live Financial Intelligence Dashboard

A production-grade interactive dashboard built with Python & Plotly Dash, 
analysing Fortune 500 financial data from real 10-K annual reports (2009-2023).

## Live Demo
https://nexus-analytics-272h.onrender.com

## What It Shows
- Total Revenue, Avg Net Income, ROE & Market Cap KPIs
- Revenue vs Net Income trend (2009-2023)
- Top 10 companies by Market Cap
- ROE vs ROA scatter analysis by sector
- Interactive Year and Sector filters

## Tech Stack
- Python
- Plotly Dash
- Pandas
- Gunicorn
- Deployed on Render

## Dataset
Fortune 500 Financial Statements 2009-2023
Source: Kaggle (Real 10-K Annual Report Data)
